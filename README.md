# Oasis Infobyte Web Development Internship

## Level 2 Projects

This repository contains the projects completed as part of my **Web Development and Designing Internship at Oasis Infobyte**.

The projects were developed to enhance practical skills in front-end web development, responsive design, JavaScript programming, DOM manipulation, data storage, and basic authentication concepts.

---

## 📂 Projects

### 🧮 Task 1: Calculator

A responsive calculator web application capable of performing basic arithmetic operations.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Clear functionality
- Responsive user interface

**Technologies Used:**
- HTML
- CSS
- JavaScript

---

### 👨‍🔬 Task 2: Tribute Page

A tribute website dedicated to **Dr. A. P. J. Abdul Kalam**, showcasing his life, achievements, contributions, and inspirational journey.

**Features:**
- Biography and introduction
- Information about achievements
- Attractive layout
- Images and typography
- Responsive design

**Technologies Used:**
- HTML
- CSS

---

### ✅ Task 3: To-Do Web App

A functional task management application that helps users organize and manage their daily tasks.

**Features:**
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Separate pending and completed tasks
- Task counters
- Task timestamps
- LocalStorage persistence

**Technologies Used:**
- HTML
- CSS
- JavaScript
- LocalStorage

---

### 🔐 Task 4: Login Authentication System

A user authentication system that allows users to register, log in, and access a protected dashboard.

**Features:**
- User registration
- Login authentication
- Password validation
- Duplicate user detection
- Password hashing
- Protected dashboard
- Session management
- Logout functionality
- Responsive design

**Technologies Used:**
- HTML
- CSS
- JavaScript
- LocalStorage
- SessionStorage
- Web Crypto API

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- SessionStorage
- Web Crypto API
