# 🔐 Login Authentication System

A responsive Login Authentication System developed using HTML, CSS, and JavaScript.

## Features

- User Registration
- Login Authentication
- Password Validation
- Duplicate User Detection
- SHA-256 Password Hashing
- Protected Dashboard
- Session Management
- Logout Functionality
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage
- Web Crypto API

## Project Structure

LoginAuthentication/
│
├── index.html
├── register.html
├── dashboard.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the project.
2. Open the folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Create an account.
5. Login using your credentials.
6. Access the protected dashboard.
7. Logout when finished.
