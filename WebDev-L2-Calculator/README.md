# 🧮 Calculator Web Application

A simple and responsive browser-based calculator developed as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2, Task 1**.

## 📌 Project Overview

This project is a fully functional calculator that performs basic arithmetic operations through an easy-to-use button interface.

The calculator supports addition, subtraction, multiplication, division, decimal values, clearing the display, deleting the last entered character, and handling division-by-zero errors.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## ✨ Features

* Numeric buttons from 0–9
* Decimal point support
* Addition operation
* Subtraction operation
* Multiplication operation
* Division operation
* Equals button for calculation
* Clear button
* Backspace/Delete button
* Division-by-zero error handling
* Operator chaining
* Responsive design
* CSS Grid button layout
* JavaScript event listeners
* No inline `onclick` attributes
* No `eval()` function

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it using Live Server or open the HTML file directly in a browser.
5. Use the calculator buttons to perform calculations.

## 🧪 Example Operations

```text
5 + 3 = 8
10 - 4 = 6
6 × 7 = 42
20 ÷ 4 = 5
5.5 + 2.5 = 8
```

The calculator also displays an error message when attempting to divide by zero.
